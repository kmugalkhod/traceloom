# Lessons

Version-controlled post-mortems that future investigations read. One file per incident:
`YYYY-MM-<slug>.md` with: what happened, detection (metric/band/tier), diagnosis, action taken and who
authorised it, the fix PR, the eval added, and the CLAUDE.md line added (if any).

`/sdlc:triage` reads this folder before diagnosing, so a repeat incident starts from what was learnt.
