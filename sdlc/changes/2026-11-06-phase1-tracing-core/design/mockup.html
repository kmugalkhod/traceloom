Foundations

Foundations

Tokens, type, controls and states shared by every screen. Switch the page theme with the toolbar button. Every frame below uses the same CSS variables, which are copied from DESIGN.md.

App shell, theme and error pages

T-5

Left nav, top bar (org / project picker, environment, date range, theme, account), bottom tabs at 390px. Theme follows the system and a toggle persists the choice. 403 and 404 render inside the shell; the ? key opens the shortcut help.

Sign-up, login, logout and password reset

T-6

Split layout on wide screens, one column below 1100px. Inline errors sit under the field and name the fix; the reset response never says whether the address exists; rate limit shows a plain banner with the wait.

Logout is the account menu item "Log out" (top right). It posts a CSRF-protected form and lands on Log in with the banner "You are logged out."

Organizations, projects, members and invites

T-7

The org / project picker shows the role you hold in each organization. Controls a role cannot use are not rendered: an Admin sees no Owner option and no Delete organization.

API keys and model definitions

T-8

The secret appears once, in a success panel that says so; revoked keys stay listed and say they get 401. Members and Viewers see a plain 403-style panel. Project model definitions are marked as overriding the built-in price.

Traces list

T-16

Soft, rounded panels on a quiet desk. A thin level marker on each row, plus an icon and a word for Error and Warning, mono numerics, tabular columns. All filter state is in the URL. The j / k cursor is the focus-coloured outline on row 2. Under 760px every row becomes a two-line strip.

The 5th row is a trace named literally <script>alert(1)</script>. It renders as text; no dialog fires.

Trace detail

T-17

Left: tree / timeline / graph. Right: selected observation with Formatted, JSON and Markdown modes. ERROR rows are red with an icon and a word; WARNING rows are amber. The first frame is live: click the tabs, press t or e.

Comments, scores, bookmark and tags

T-19

Members get a bookmark button, removable tags, a comment box and an Add score form. Viewers see the same facts with none of those controls. Scores read name: value with source and author.

Public share, delete and audit log

T-20

Share is a switch in the trace header (Admin+), and shows the public link when on. Delete by filter shows the match count in the title, in the warning and in the button, and asks to type the count. The public page has no nav and a dark read-only bar.

Sessions and users

T-22

Sessions list with sort and cursor pagination; the replay shows each turn as the user side then the assistant side with cost and latency, and totals at the top. Users link to filtered traces.

Dashboard

T-23

Every FR-D1 panel: counts, cost and tokens by model, latency percentiles by name and by model, error rate by level, top users, traces over time. Charts are drawn with series colours that stay distinct in both themes and every bar carries its number.
