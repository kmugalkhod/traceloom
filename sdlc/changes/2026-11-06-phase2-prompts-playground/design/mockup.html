What is new in the design standard

Foundations

Phase 2 reuses every Phase 1 token. Nothing below changes a colour, font, radius or shadow; it only adds components built from them. The nav gains a Build group (Prompts, Playground) and Settings gains LLM connections and Webhooks tabs for Admins.

Mockup only: the gallery bar and frame captions are not part of the product. Use the Light/Dark switch at the top to check both themes. Frames use container queries, so the 390 px frames are the real mobile layout.

Declutter: before and after on existing pages

App-wide

Same colours, fonts and v3 look; only density changes. Base text 15px at 1.55 line height (was 14px), page titles 32px, 60px table rows (was 48px), 44px controls, 32px between sections, 40px page padding. Fewer lines: panel headers, table header bars, stat dividers and nested boxes lose their borders; one primary action per view. Compare each Before with the After beneath or beside it. Phase 1 pages in the After frames gain the Build nav group.

Prompts list, new prompt and version editor

T-6

Folder tree from "/" in names, search over name, tag and content, filters by tag and label, sortable columns. Viewers get no New prompt button; a Viewer who opens /prompts/new gets a 403 panel. Variables are highlighted in the editor and listed beside it; content such as a script tag renders as text.

Prompt detail: versions, diff, labels and preview

T-7

Hierarchy is title, then content, then metadata. A quiet version rail on the left picks the version; the right side shows its content with the labels and one Set production action. The Admin moves production in one click and gets a toast and an audit row; a Member sees it disabled with the reason; the server still returns 403. Secondary actions live in the more menu.

Metrics tab partial

T-9

Loaded into the tab by GET /project/{id}/prompts/{name}/metrics. It follows the environment and range in the context bar, plus a version select. Rows link to trace detail.

Settings: Webhooks

T-17

Admin only. Add a webhook, see the secret once, send a test and watch the delivery row appear. Private URLs fail inline. Members get a 403 panel and the tab is not rendered.

Settings: LLM connections

T-24

One form per provider with exactly the fields it needs. A saved key is never rendered again: only "ends in …a91f" and a Replace key action. Test connection reports success or a scrubbed provider error.

Playground: editor, streaming and single run

T-25

The editor and the response get equal, wide columns. Run is the one primary action (it becomes Stop while streaming). Parameters, tools and schema live in a Settings side panel that opens on demand; Compare, Load prompt and Save as prompt are in the more menu. Provider output and messages render as text.

Playground: compare view

T-26

Up to 4 variants; the Add variant button disables at 4 and says why. Columns have a letter badge, model, parameters, their own streaming text and their own usage and cost. At 1100px and below the columns stack.

Save as prompt and Open in playground

T-27

Saving creates the next version of an existing chat prompt or a new prompt at v1, with a required commit message. Protected labels follow the role. Open in playground sits in the generation panel header for Members and Admins; Viewers do not get it.
